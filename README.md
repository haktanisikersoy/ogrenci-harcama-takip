# ogrenci-harcama-takip
Öğrencilerin aylık harcamalarını takip etmesini sağlayan basit web uygulaması

## Proje Hakkında
Üniversite öğrencileri çoğu zaman sınırlı bir bütçeyle yaşıyor ve ay sonunda paranın nereye gittiğini bilmiyor. Bu uygulama, öğrencilerin harcamalarını kategoriye göre kaydetmesini ve aylık harcama özetini görmesini sağlar. Böylece bütçelerini daha bilinçli yönetebilirler.

**Kimin için:** Harçlık, burs veya part-time gelirle geçinen ve bütçesini kontrol altında tutmak isteyen üniversite öğrencileri.
